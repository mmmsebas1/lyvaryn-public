# LYVARYN — Business Management Platform Website

**A modern, responsive website designed to present a business management platform, its features, pricing plans, and contact options.**

🌐 **Live Demo:** https://mmmsebas1.github.io/lyvaryn-public/  
💻 **Source Code:** https://github.com/mmmsebas1/lyvaryn-public

## Overview

LYVARYN is a web development project focused on presenting a business management platform through a modern, accessible, and responsive user interface.

The website showcases platform features, pricing plans, integrations, and contact information, providing visitors with a clear way to explore the service and get in touch.

## Key Features

- Responsive layout for desktop and mobile devices.
- Modern user interface with light and dark themes.
- Landing page with product information and feature sections.
- Pricing plans and calls to action.
- Dedicated pages for features, pricing, contact, and legal information.
- WhatsApp integration for direct customer inquiries.
- Reusable CSS components and JavaScript interactions.
- Public deployment using GitHub Pages.

## Technologies Used

- **HTML5** — Page structure and semantic markup.
- **CSS3** — Styling, responsive layouts, animations, and themes.
- **JavaScript** — Client-side interactions and dynamic behavior.
- **Git & GitHub** — Version control and source code management.
- **GitHub Pages** — Static website hosting.

## Project Goals

- Build a professional web presence for a digital product.
- Practice responsive frontend development.
- Organize styles and assets into a maintainable structure.
- Deploy a public website using GitHub Pages.
- Present product information through a clear user experience.

## What I Learned

Through this project, I worked on frontend structure, responsive design, CSS organization, JavaScript interactions, version control, and static website deployment.
